{{/* a robust diagnostic-friendly shortcode that: - ✅ Directly matches video `.md` files in `content/{{ path }}/` by filename (e.g. `GgKjYzKJ4I.md`) - ✅ Avoids relying on frontmatter like `youtubeID` - ✅ Adds diagnostic messages for: 1. Section path lookup 2. Matched IDs 3. Unmatched IDs - ✅ Provides safe fallback rendering if no videos are matched - ✅ Compatible with Hugo pages that include shortcode like `{{< curated-videos-yt ids="GgKjYzKJ4I,PpKxYzKJ9I" path="videos_youtube" >}}` --- ### ✅ Ensure your files are structured like: ```plaintext content/ └── videos_youtube/ ├── GgKjYzKJ4I.md └── PpKxYzKJ9I.md ``` --------------------------------------------- */}} {{- /* 1. Parse & trim comma-separated IDs */ -}} {{- $raw := split (.Get "ids") "," -}} {{- $ids := slice -}} {{- range $raw -}} {{- $ids = $ids | append (trim . " ") -}} {{- end -}} {{- /* 2. Section folder where your .md files live */ -}} {{- $section := .Get "path" | default "videos_youtube" -}} {{- /* 3. Lookup pages by filename, collect hits & misses */ -}} {{- $matches := slice -}} {{- $missed := slice -}} {{- range $ids -}} {{- with site.GetPage (printf "%s/%s" $section .) -}} {{- $matches = $matches | append . -}} {{- else -}} {{- $missed = $missed | append . -}} {{- end -}} {{- end -}} {{- /* 4. Warn if any IDs didn’t resolve */ -}} {{- if gt (len $missed) 0 }}

⚠️ Could not find pages for IDs: {{ delimit $missed ", " }} (check content/{{ $section }})

{{- end -}} {{- /* 5. Render each page’s .Content (bullet list + youtube shortcode) */ -}} {{- if gt (len $matches) 0 }}
{{- range $matches }}

{{ .Title }}

{{ .Summary | safeHTML }}
{{ .Content | safeHTML }}
{{- end }}
{{- else }}

ℹ️ No videos matched for IDs: {{ delimit $ids ", " }} (check your shortcode call or filenames)
