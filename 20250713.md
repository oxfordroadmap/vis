## Mobile-only non-transparent gradient background

### CSS classes expressions
How do I implement non-transparent gradient background (white and black when dark mode) near the top of the screen? The will only take effects during mobile. Please use TailwindCSS?

fixed inset-x-0 top-0 h-16 
block md:hidden pointer-events-none z-50
bg-gradient-to-b from-white to-white/0 dark:from-black dark:to-black/0

* c.f. z-100 (for toggle)

---
You can drop a full-width, fixed `<div>` at the very top of your mobile layout that fades from solid white (or black in dark mode) down to transparent. Tailwind makes it dead-simple:

```html
<!-- put this as the first child of <body> (or inside a relative container) -->
<div
  class="
    fixed inset-x-0 top-0 h-16      /* full-width, 4rem tall */
    bg-gradient-to-b                /* vertical gradient */
    from-white to-white/0           /* light mode: white→transparent */
    dark:from-black dark:to-black/0 /* dark mode: black→transparent */
    pointer-events-none             /* clicks pass through */
    block md:hidden                 /* only on <md (mobile) screens) */
    z-50                            /* above everything else */
  "
></div>
```

Explanation:

- `fixed inset-x-0 top-0 h-16` pins a 4 rem-tall bar to the top.
- `bg-gradient-to-b from-white to-white/0` creates a white→transparent gradient.
- `dark:from-black dark:to-black/0` swaps in black→transparent in dark mode.
- `block md:hidden` shows it on mobile (`<768px`) and hides on larger screens.
- `pointer-events-none` ensures it won’t block any underlying buttons or links.
- `z-50` (or whatever fits your z-index scheme) keeps it above your content.

Adjust `h-16` to whatever height you want the fade to cover.

### @apply
Target: div class="page-body" How can I implement the above TailwindCSS class effects onto the target using @apply? Please be specific where to put it elegantly so that it will work as intended (on mobile devices).
<!-- page-body: Div to include block main -->

Add this to your main Tailwind CSS file (e.g. `assets/css/main.css`), **after** your `@tailwind` statements, inside a `@layer components` block. It will inject a pseudo-element gradient on `.page-body` only on screens smaller than `md`:

```css
/* assets/css/main.css */
@tailwind base;
@tailwind components;
@tailwind utilities;

@layer components {


  /* mobile only (<md) */
  @screen max-md {
    .page-body {
      position: relative; /* ensure pseudo‐element is positioned relative to this container */
    }
    .page-body::before {
      content: "";
      @apply fixed inset-x-0 top-0 h-16
             bg-gradient-to-b from-white to-white/0
             dark:from-black dark:to-black/0
             pointer-events-none
             z-50;
    }
  }


}
```

---

Explanation:

1. Place it **after** your `@tailwind` imports so Tailwind has already generated all utilities.
    
2. Wrap in `@layer components` so it’s bundled with your component styles.
    
3. Use `@screen max-md` to scope everything to **mobile** (`<768px`).
    
4. You need `position: relative` on `.page-body` so its `::before` (absolutely fixed to the viewport) sits above the content.
    
5. The `::before` block applies the same gradient classes you’d normally write in-HTML, but via `@apply`.
    

Now your `<div class="page-body">…</div>` will get a top white→transparent fade on mobile and switch to black→transparent in dark mode.

## How and why 

How and why @screen max-md will work?

---
Great question, Liao — here’s how `@screen max-md` works and why it’s an elegant way to apply mobile-only styles in Tailwind’s compiled CSS.

### 📐 What Is `@screen max-md`?

It’s a Tailwind **responsive directive** that expands to a media query:

css

```
@screen max-md { /* … */ }
```

is equivalent to:

css

```
@media (max-width: 767px) { /* … */ }
```

So it targets screens that are **below the** `md` **breakpoint** — i.e. mobile phones and smaller tablets.

### 🧠 Why It Works in Tailwind

Tailwind uses `@screen` shorthand inside `@layer` blocks to compile responsive styles automatically based on your configured breakpoints:

- `md` usually refers to `min-width: 768px`
    
- `max-md` is **not a built-in alias**, but if you're using Tailwind v3.3+, you can define it manually like this:
    

js

```
// tailwind.config.js
module.exports = {
  theme: {
    extend: {
      screens: {
        'max-md': { max: '767px' },
      },
    },
  },
};
```

This lets you write:

css

```
@screen max-md {
  .page-body::before { @apply … }
}
```

and Tailwind will generate a proper `@media (max-width: 767px)` block in your final CSS.

### ✅ Why It’s Elegant

- Keeps your breakpoint logic centralized in the config
    
- Allows CSS overrides scoped to specific screen ranges
    
- Fits beautifully in Hugo or PostCSS pipelines using `@layer`
