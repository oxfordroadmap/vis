### Four Versions 
The following four versions are available for ***learners without any software development knowledge***:

#### 🪴 [Agentic Web Development]({{% ref path="/teaching/curriculum-agentic_webdev" %}}) 

- 🗓️ **(Bare) 5+2 Course**
    - 🥯 The most condensed and updated curriculum, delivering integrated Web and AI Agent development learning
    - 🧐 Suitable for hackathons, summer schools, or continuous education

#### 🌲 `AI Agent & Internet`

- 🗓️ **(Core) 10+2 Course**
    - 🥪 A condensed and updated curriculum
    - 🤖 Delivers integrated Web and AI Agent development learning
    - 🧑🏾‍🏫 Suitable for any undergraduate program

#### 🎄 `Agentic New Media & Internet`

- 🗓️ **(Full) Revised 18-Course Version**
    - 🍔 Updated with the latest Web and AI Agent development learning
    - 🎯 Suitable for cultivating Internet **Product Managers**, **UI/UX Designers**, and **Front-End Developers**
    - 🧠 Focused on integrating **AI agentic** capabilities and other **API resources** to solve real-world problems

#### 🌲 `New Media & Internet`

- 🗓️ **(Base) Original 19-Course Version**
    - 🏫 Implemented and executed in a university in China
    - 🎯 Focused on cultivating Internet **Product Managers**, **UI/UX Designers**, and **Front-End Developers**
    - ☁️ Emphasizes integration of **API cloud resources**
