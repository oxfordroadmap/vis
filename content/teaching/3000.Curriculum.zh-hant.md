# ⓷ 課程地圖概覽 🛣️

對於沒有軟體開發背景的學習者，以下四個版本的課程地圖可能對學習者與教育工作者皆有幫助。

### 四個版本

以下四個版本適用於_**完全沒有軟體開發知識的學習者**_：

#### 🪴 `Agentic Web Development`【智能體應用開發】

- 🗓️ **（精簡版）5+2 課程**
    
    - 🥯 最精簡且最新的課程，融合 Web 與 AI Agent 的開發學習
        
    - 🧐 適合用於黑客松、暑期學校或推廣教育
        

#### 🌲 `AI Agent & Internet`【智能體與網際網路】

- 🗓️ **（核心版）10+2 課程**
    
    - 🥪 一套精簡且更新的課程
        
    - 🤖 提供融合 Web 與 AI Agent 的開發學習
        
    - 🧑🏾‍🏫 適用於各類大學部課程地圖
        

#### 🎄 `Agentic New Media & Internet`【智能體時代下的網路與新媒體】

- 🗓️ **（完整版）修訂後的 18 門課程**
    
    - 🍔 更新為最新的 Web 與 AI Agent 開發學習內容
        
    - 🎯 適合培育網路領域的 **產品經理**、**UI/UX 設計師** 及 **前端工程師**
        
    - 🧠 著重整合 **AI Agent 能力** 與其他 **API 資源**，以解決真實世界問題
        

#### 🌲 `New Media & Internet`【網路與新媒體】

- 🗓️ **（基礎版）原始 19 門課程**
    
    - 🏫 已於中國某大學實際執行
        
    - 🎯 著重培育網路領域的 **產品經理**、**UI/UX 設計師** 及 **前端工程師**
        
    - ☁️ 強調整合 **API 雲端資源** 的開發能力
