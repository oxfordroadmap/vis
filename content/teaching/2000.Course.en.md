### AG1XX Courses – Agentic Web Development

| Course Code | Course Name                        | Unicode Icon | Description                                                                                                                                                                                                                                                                                                                                     |
| ----------- | ---------------------------------- | ------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `AG101`     | Web Development **with** AI Agents | 🐙           | Learn to build structured web applications by applying AI agents into frontend and backend development processes and workflows. Learners practise Hugo site, CI/CD pipelines, code assistants using Github and VSCode.                                                                                                                          |
| `AG102`     | Web Development **for** AI Agents  | 🤗           | Learn to incorporate online LLM resources into web applications. Learners apply HuggingFace APIs, CI/CD pipelines, code assistants using Github, use UI widgets needed for agentic interaction. Topics include Agentic Web Interface (AWI) principles, semantic DOM distillation, and building LLM-friendly environments for autonomous agents. |

Topics include semantic rendering, reactive interfaces, multi-agent visualization orchestration. |
