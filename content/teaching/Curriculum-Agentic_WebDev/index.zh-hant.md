## ⚡TLDR 課程簡介

`{{% param "emoji" %}}{{% param "curriculum" %}}` 課程地圖引導學生探索 AI 整合式 Web 開發的前沿技術，著重於智能體設計、多語言適應力及檢索增強生成（RAG）邏輯的實務應用。透過實作型單元與影響導向的專題計畫，學生不僅習得 Web 開發技能，更能深化智能體邏輯設計、決策語境建構，並於倫理、參與與資料導向架構中思考未來科技的發展方向。

📚課程共分為 **三個漸進階段**，涵蓋 **5+2 個課程單元**，可依學期制或自我節奏彈性修習：

- 🧭 **第一階段：基礎起步** — _AG101 至 AG102_  
    學生將掌握 Web 技術基礎，運用 API 開發智能體功能，並透過 🤗 Hugging Face 與 🐙 GitHub 平台整合語言模型。
    
- 🔁 **第二階段：創意實作** — _AG201 至 AG203_  
    聚焦於結構化表達、RAG 系統與智能體視覺化設計，學生將開發具備回應力、多語處理與解釋能力的互動式應用。
    
- 🚀 **第三階段：整合與影響** — _AG303 與 AG302_  
    學生將彙整成果並建立公開作品集，實施科學知識圖譜繪製，並藉由技術預測與責任創新框架分析 AI 的社會影響力。

### ✨課程亮點

- 🔧 **打造** 真實情境中的智能體 Web 應用，結合 🤗 Hugging Face 與 🐙 GitHub 平台部署大型語言模型（LLM）
- 📦 **開發與呈現** 結構化的多語內容與產品規劃流程（PRD），強化智能體表達與系統模組化設計
- 🔗 **整合與預測** 資料、決策與敘事內容，以倫理導向設計互動式儀表板，並支援原始碼共享與科學知識圖譜成果展示

---

### 🎯學習成果

完成本課程後，學生將具備以下能力：

- 🖌️ **建構** 現代化 Web 架構及整合 LLM 技術的互動式應用
- 📑 **撰寫** 符合 W3C 無障礙標準與可持續設計原則的智能體產品需求文件（PRD）
- 🧰 **溝通** 專案決策與價值主張，具備跨技術生態與實踐社群（CoPs）溝通能力
- 🎨 **設計** 符合倫理考量且回應使用者語境的資料視覺化與智能體介面
- 🧪 **評估** 應用 AI 評量方法、科學知識圖譜繪製技術與前瞻性策略，分析創新場景與社會影響

## 🔖課程體系詳情

本課程體系透過專案文件與說明性成果，持續充實學習者的作品集，引導其完成三個階段的學習歷程。每個階段旨在深化學生的技術敏感度、創新實踐力、智能體設計潛能，以及倫理反思能力——_**無須任何程式背景**_。學習者自掌握 Web 開發基礎技能起步，逐步進階至設計智能體互動介面，最終整合創新成果並回應真實世界挑戰。

### 🧭第一階段：基礎建置 — _AG101 至 AG102_

聚焦於 API 應用與大型語言模型（LLM）的入門整合，學生將建構具回應性的 Web 架構，並體驗 AI 助力下的互動設計流程。

#### 🐙 **AG101：Web開發(精用AI助手)**

- 🧠 **基礎技能建構**：學習 Web API、HTML、CSS、JavaScript 與 HTTP 流程，搭配 AI 編碼助手進行互動實作
- 🧩 **模組化系統設計**：採用 Hugo、TailwindCSS 及 GitHub，打造具多語支援、響應式與元件化的網站架構
- 🐙 **GitHub 協作流程**：熟悉版本控管、專案文件撰寫與公開展示，逐步建立個人作品集
- 📦 **成果展示**：繳交具備功能性、可擴充性與多語能力的網站作品，標誌著 Web 開發進入智能體創作新階段

#### 🤗 **AG102：智能體Web開發**

- 🛠️ **LLM API 整合應用**：在地端與雲端執行語言模型接入，探索三類智能架構：① 公開網站＋聊天機器人，② 私有筆記本＋本地模型，③ 影片策展平台＋自動化流程
- 🔄 **智能體互動流程**：專案涵蓋具回應性、預測性與迭代性的互動元件，設計能貼近使用者需求與倫理思考的介面行為
- 🤗 **Hugging Face 模型部署**：整合模型推理 API，實作自訂任務與對話流程，建構具情境感知能力的智能體網頁應用
- 📦 **成果展示**：交付具結構性、互動性與語意邏輯的進階作品，開展對智能體設計與使用者決策體驗的初步理解

### 🔁第二階段：產出創作 — _AG201、AG202、AG203_

在掌握 LLM 基礎整合後，學生將於本階段探索 AI 系統中的智能體能力。課程圍繞三項主題展開：**結構化表達**、**RAG 系統**與**智能體資料視覺化**，最終產出人機協同的專案成果與解釋性作品。

#### ♞🧱 **AG201：智能體通傳結構化**

- 🧠 **結構化**：學生學習如何透過結構化的 LLM 模型規範、Markdown 圖表、產品需求文件（PRD）、互動敘事及多語內容進行智能化通訊与傳播。
- 🤝 **實踐社群（CoP）交流**：於跨技術生態與產業社群中交流作品，強調設計選擇、語境辨識與溝通清晰度。
- 📦 **成果呈現**：專案成果以作品網站形式展示，突顯使用者體驗的清晰性與文化適配力，聚焦「語境工程」與「提示工程」，展現智能體系統的設計理念。

#### ♝🍞 **AG202：檢索增強生成系統**

- 🔗 **資料結構與檢索流程**：設計以檢索增強生成（RAG）為核心的系統，比較結構化與非結構化資料流程，並探索傳統與圖譜式 RAG 架構。
- 🤝 **實踐社群（CoP）嵌入**：專案嵌入具體領域情境，探討 RAG 系統於新聞、公民科技及學術研究中的差異應用。
- ⚙️ **前後端整合開發**：同步開發前端（搜尋與聊天機器人功能）與後端（知識語料建構與流程編排）。
- 📦 **成果呈現**：最終作品展現具語境感知能力的互動設計，強調資料流程編排在智能體應用中的關鍵作用。

#### ♛🖼️ **AG203：智能體資料視覺化**

- 👁️‍🗨️ **決策觸點呈現**：建置互動式儀表板，不僅視覺化資料，更呈現**決策語境、解釋性結構與認知不確定性**。
- 🧩 **人機協同決策流程**：探討人類與智能體如何共同參與決策流程，強調「人在回路」（Human-in-the-Loop）與資料驅動原則。
- 🧬 **符號與認知結構探索**：研究敘事能動性、知識建模與文化符號，並運用視覺語言建構解釋框架。
- 📦 **成果呈現**：最終儀表板作為智能體系統呈現，賦予使用者質詢資料、共同創作，並轉化為具倫理反思的實際行動。

### 🚀第三階段：總整與影響 — _AG303 與 AG302_

本階段聚焦於學習成果的彙整呈現、專業傳播與科技前瞻。學生將啟動創新實踐心態，透過智能體應用、責任導向設計與跨語言交流深化成果影響。重點在於將成果對接多元**實踐社群（CoP）**，並以結構化評估標準與同儕評審與排練，來展示 AI 創新實力與社會意涵。

#### 🧪🧭 **AG303：AI工程**
可另命名為**AI工程總整**、**智能體專案總整**、或**實踐社群與專案總整**

- 🧵 **成果專案總整 Capstone**：學生將歷程成果彙整於可公開瀏覽的作品集平台，完整梳理開發文件與設計脈絡，呈現能力成長歷程。
- 📬 **專業與多語溝通**：針對不同社群設計溝通策略，兼顧跨語言呈現能力與專業知識傳達力。
- 🔗 **開源協作實踐**：運用 GitHub 等平台提升專案可見度，包括原始碼連結、協作流程與跨社群 mentoring 行動。
- 📦 **成果展示**：透過同儕 walkthrough 模式展示作品，突顯使用者體驗（UX）清晰度、可近性與社群實用性。

#### 🧬📡 **AG302：AI影響**
可另命名為**AI影響預測**、**智能體影響評估**、或**科學知識圖譜繪制與 AI 影響評估*

- 🗺️ **技術趨勢分析**：利用專利或學術資料庫進行科學知識圖譜繪製，分析技術演化與創新機會。
- 🔮 **責任創新框架導入**：探討倫理設計選擇與潛在社會影響，結合預測治理與責任技術模型。
- 📊 **結構化評量與敘述**：以可持續性、跨文化溝通力與知識透明度為核心進行成果評量與內容敘述。
- 📦 **成果展示**：透過模型解釋與創新預測傳達關鍵洞察，並連結作品與實踐社群的成功挑戰與制度意涵。
