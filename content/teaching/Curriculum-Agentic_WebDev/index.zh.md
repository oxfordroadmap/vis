## ⚡TLDR 课程体系简介

该`{{% param "emoji" %}}{{% param "curriculum" %}}` 课程体系引导学习者探索 AI 集成网页系统的前沿，重点强调智能体设计、多语种适配与 RAG（检索增强生成）逻辑。通过模块化学习与实践导向项目，学生不仅掌握应用开发，更学会如何构建智能体系统、表达建模决策语境，并在伦理、协作和数据响应的架构中思考未来智能创新。


📚课程分为**三个循序渐进的阶段**，共包含**5+2 个课程模块**，可灵活适应（大学）学期制 或 自主学习节奏 安排：

- 🧭 **第一阶段：基础构建** — _AG101 至 AG102_：通过 API 实现智能体功能，学生掌握网页应用开发基础技能，并通过平台如 🤗 Hugging Face 和 🐙 GitHub 集成语言模型。
    
- 🔁 **第二阶段：产出创作** — _AG201 至 AG203_：学生通过结构化表达、RAG 系统与智能体数据仪表盘，开发具响应性、多语及智能解释能力的应用。
    
- 🚀 **第三阶段：影响力总结** — _AG303 和 AG302_：学生将学习成果项目整合为可公开访问的作品集，开展科学知识图谱绘制，并通过预测与前瞻性方法评估 AI 创新影响。    

### ✨课程亮点

- 🔧 **构建** 集成大型语言模型（LLM）的智能体网页应用，结合 🤗 Hugging Face 和 🐙 GitHub 的代理性 Web 应用，实现真实场景功能
    
- 📦 **交付与部署** 多语种表达系统，结合结构化数据、产品需求文档（PRD）与智能体工作流，实现智能部署
    
- 🔗 **整合与预测** 数据、决策与叙事内容，打造具伦理意识的适应型仪表板，包括代码共享开源与科学知识图谱绘制成果展示
        

### 🎯学习成果

课程结束后，学生将具备以下能力：

- 🖌️ **构建** 基于现代 Web 框架的结构化网页应用 与 交互式 LLM 系统
- 📑 **撰写** 能生成可行代码、对齐 W3C 无障碍标准与可持续设计理念的专业 `智能体产品需求文档`（智能体PRD）
- 🧰 **沟通** 项目决策与价值主张，面向相关技术生态与实践社群（CoPs）    
- 🎨 **设计** 响应用户语境与伦理考量的数据可视化与智能体界面
- 🧪 **评估** 使用 AI 评估方法、科学知识图谱绘制工具、责任 AI 框架与前瞻性方法识别创新场景与影响路径


## 🔖课程体系详情

本课程体系通过项目文档与解释性成果不断丰富学习者的作品集，引导学生完成三个阶段的学习旅程。每个阶段旨在深化学生的技术敏感度、创新能力、智能体设计潜能以及伦理思辨能力——_**无须任何编程背景**_。学习者从掌握网页开发基础开始，逐步发展智能体界面，并最终将创新成果与社会影响进行整合。

### 🧭第一阶段：基础构建 — _AG101 至 AG102_

本阶段聚焦于基于 API 的网页开发与基础 LLM（大型语言模型）集成。学生将构建模块化网页架构，并初步塑造具响应能力的 AI 用户体验。

#### 🐙 **AG101：Web开发（精用AI助手)**

- 🧠 **网页基础技能**：学生将学习 Web API 与网页设计核心原则，包括 API/HTTP/HTML/CSS/JS 基础知识，并借助 AI 编码助手进行实践操作
    
- 🧩 **模块化设计**：重点构建响应式、多语种、组件化的网站架构，使用 Hugo、TailwindCSS 及 GitHub 工具链
    
- 🐙 **GitHub版本控制与协作**：学生使用 GitHub 管理版本、项目文档，并共享模块化模板，逐步打造公开作品集
    
- 📦 **交付与演示**：学生提交具功能性、多语种支持且可扩展的个人作品网站，标志着其迈入基于 Web 的智能体创作之旅
    

#### 🤗 **AG102：智能体Web开发**

- 🛠️ **LLM API集成**：学生在本地与云端实践 API 接入的大型语言模型，并探索三类结构化应用：①公开网站 + 聊天机器人，②私有智能笔记本 + 本地模型，③YouTube 策展网站 + 自动化流程
    
- 🔄 **智能体网页特性**：项目涵盖具响应性、前瞻性与迭代性的网页组件，塑造可适应用户需求与伦理考量的互动流程
    
- 🤗 **Hugging Face部署**：学生探索 Hugging Face 模型库及推理 API，将语言模型嵌入定制化工作流，激活智能体功能
    
- 📦 **交付与演示**：学生提交结构更清晰、交互性更强的进阶网页应用，并开始理解智能体设计如何塑造用户体验与决策逻辑
    

### 🔁第二阶段：产出创作 — _AG201、AG202、AG203_

在掌握 LLM 基础集成之后，学生将在本阶段探索 AI 系统中的智能体能力。课程围绕三个主题展开：**结构化表达**、**RAG 系统**与**智能体数据可视化**，最终实现人机协同的应用成果与解释性输出。

#### ♞🧱 **AG201：智能体通传结构化**

- 🧠 **结构化**：学生学习如何透过结构化的 LLM 模型规范丶Markdown 图表丶产品需求文件（PRD）丶互动叙事及多语内容进行智能化通讯与传播。
    
- 🤝 **实践社群（CoP）**：学生在跨技术生态系统与行业社群中分享实验成果，强调设计选择、语境辨析与沟通清晰度
    
- 📦 **交付与演示**：成果以作品网站形式呈现，强调用户体验清晰性与文化适配能力。项目聚焦 `语境工程` 与 `提示词工程`，以体现智能体系统设计理念
    

#### ♝🍞 **AG202：检索增强生成系统**

- 🔗 **数据结构与检索**：学生设计基于检索增强生成（RAG）系统，以比较结构化与非结构化数据流程，并探索经典与图谱式 RAG 架构
    
- 🤝 **实践社群（CoP）**：项目嵌入具体社群情境，揭示 RAG 系统在新闻、公民科技与学术领域的差异性应用
    
- ⚙️ **前后端集成开发**：学生同时开发前端（搜索与聊天机器人功能）与后端（知识语料结构与流程编排）
    
- 📦 **交付与演示**：最终交付的 RAG 应用展示了具上下文感知能力的互动设计，体现数据流编排在智能适应中的关键作用
    

#### ♛🖼️ **AG203：智能体数据可视化**

- 👁️‍🗨️ **决策触点映射**：学生构建互动式数据仪表盘，不仅可视化数据，还呈现**决策语境、解释性结构与认知不确定性**
    
- 🧩 **人机协同流程**：项目探讨人类与智能体如何共同参与决策流程，强调“人在回路”（Human-in-the-Loop）与数据驱动决策原则
    
- 🧬 **符号与认知结构**：学生研究叙事能动性、知识建模与文化符号表达，并将其融入视觉语言与解释框架中
    
- 📦 **交付与演示**：最终仪表盘作为智能体系统呈现，赋予用户质询数据、共同创作并将数据转化为伦理反思性行动的能力

### 🚀 第三阶段：总整與影响 — _AG303 与 AG302_

本阶段聚焦于学习成果的总结整合丶专业传播与技术前瞻。学生激发持续创新意识，并通过智能体应用、责任创新、跨语种沟通等方式进行成果沉淀与展示。重点在于将学习成果与各类**实践社群（CoP）**连接，并通过结构化评分标准与同行评审与排练，來呈现 AI 影响力与未来路径。

#### 🧪🧭 **AG303：AI工程**
可另命名为**AI工程总整**丶**智能体项目总整**丶或**实践社群与专案总整**

- 🧵 **成果总整 Capstone**：学生将前期学习成果融入可公开访问的整合性作品集中，梳理所有相关项目与文档，体现学习轨迹与能力成长
    
- 📬 **专业与多语种传播**：强调针对不同实践社群的沟通策略与资源部署，突出专业表达与跨语种适配能力
    
- 🔗 **开源协作实践**：通过 GitHub 等平台优化项目展示，包括提交链接、代码协作与跨社群 Mentoring 行动
    
- 📦 **交付与演示**：最终作品通过同行 walkthrough 演示，突出用户体验（UX）清晰度、可访问性与实践社群契合度
    

#### 🧬📡 **AG302：AI影响**
可另命名为**AI影响预测**丶**智能体影响评估**丶或**科学知识图谱绘制与 AI 影响评估**

- 🗺️ **技术前瞻分析**：学生借助专利或科研数据库进行科学知识图谱绘制，评估技术趋势与潜在创新路径
    
- 🔮 **责任创新框架**：重点探讨伦理设计选择与社会影响，融合责任创新与预测治理等框架方法
    
- 📊 **结构化评分与表达**：以可持续性、跨文化沟通能力与知识透明度为导向进行成果评估与叙述
    
- 📦 **交付与演示**：通过解释模型与前景预测传达关键洞察，并将个人成果与实践社群的成功／挑战进行关联
