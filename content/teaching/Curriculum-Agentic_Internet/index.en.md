## ⚡TLDR
The `{{% param "emoji" %}}{{% param "curriculum" %}}` curriculum invites learners from all disciplines into the rapidly evolving world of intelligent agent applications and AI-integrated systems. Grounded in hands-on practice and ethical systems thinking, this program combines core web technologies, large language models (LLMs), and Retrieval-Augmented Generation (RAG) with agentic UX and multimodal collaboration skills.

📚 Learners progress through **5 stages** across **🎍10 foundational + 2 capstone modules**, which together build from technical literacy to system orchestration and capstone projects. The structure is designed to accommodate semester formats or self-paced learning journeys.

### 🪜Stages

- 🧭 **Stage 1: Conceptual Foundation** — _🌐 TECHC_ Students cultivate critical digital literacy by authoring version-controlled notebooks in 🐙 GitHub. This module introduces AI agent technologies and collaborative ecosystems, grounding learners in the human–data–agent triad and sociotechnical reflection.
    

- 🦾 **Stage 2: Practical Foundation** — _🐙 AG101, 🐍 PYTHN, 🔍 ANGUX_ Learners transition into hands-on development with agentic systems: modular web interfaces (🐙 AG101), Python scripting (🐍 PYTHN), and grounded Agent UX practices(🔍 ANGUX). These modules build core skills in responsive front-end prototyping and user-context orchestration.
    
- 🔁 **Stage 3: Front-end Production & Evaluation** — _🤗 AG102, ⚙️ FRONT (or 📊 INFOV), 🧠 ANGEV_  
    This stage empowers learners to **build** intelligent, reactive applications that respond to users and agent systems. Through 🤗 AG102, students **develop** web interfaces using cloud/local APIs and CI/CD workflows; with ⚙️ FRONT (or 📊 INFOV), they **implement** adaptive data dashboards. Finally, 🧠 ANGEV **guides** them in **evaluating** system behavior, **aligning** outputs with stakeholder context through scenario modeling and impact metrics—leveraging platforms like 🤗 Hugging Face to **test** interface logic in live agentic environments.

- ⛓️ **Stage 4: Agent-heavy Production** — _♞🧱 AG201, ♝🍞 AG202, ♛🖼️ AG203_  
    Learners **advance** into agentic systems and orchestration through structured communication (AG201), RAG-enhanced pipelines (AG202), and evaluative data visualization (AG203). Learners **integrate** multilingual agent interfaces and **develop** adaptive dashboards that respond to organizational and stakeholder needs. Through aligned PM scaffolding, systems **reflect** grounded agentic reasoning, collaborative intent, and value modeling via platforms like 🤗 Hugging Face and 🐙 GitHub.

- 🚀 **Stage 5: Capstone Synthesis & Impact** — _🧑‍🤝‍🧑🧬AG303 & 📚🦠AG302_  
    Students **synthesize** their agentic systems or architectures into public-facing portfolios that **demonstrate** futures-aware values in targeted decision environments. 🧑‍🤝‍🧑🧬AG303 **curates** key considerations and insights for the targeted Community of Practice (CoP), especially in major platforms such as GitHub and Hugging Face. 📚🦠AG302 **shows** informed foresight and narrative clarity based on science mapping of patent and academic databases. Together, these capstones **demonstrate** systemic agility and context-rich innovation.

### ✨ Highlights

- 🧭 **Adopt and operationalize** AI agents in targeted domains—such as business, finance, medicine or engineering—to bridge sector-specific knowledge with scalable agentic interfaces and interaction chains
    
- 🔧 **Build** agentic web apps integrating LLMs via 🤗 Hugging Face and 🐙 GitHub for real-world functionality
    
- 📦 **Deliver and deploy** structured expressive intelligence through multilingual content, structured data, PRDs, and agentic workflows
    
- 🔗 **Synthesize and forecast** data, decisions, and storytelling into ethical, adaptive dashboards for public-facing engagement—including code sharing and science mapping

By the end of this course, students will be able to:

- 🧭 **Adopt and apply** AI agents within targeted domain contexts—such as business, finance, medicine or engineering—by aligning agentic capabilities with sector-specific goals, practices, and knowledge frameworks
    
- 🖌️ **Construct** structured web applications and interactive LLM-powered systems using modern web frameworks
    
- 📑 **Compose** AI agent product requirements documents (PRDs) structured for code-generation and aligned with professional standards, including W3C accessibility and sustainable web design principles
    
- 🧰 **Communicate** project decisions and value propositions across relevant ecosystems and Communities of Practice (CoPs)
    
- 🎨 **Design** data visualizations and agentic interfaces that respond to user context and ethical considerations
    
- 🧪 **Evaluate** innovation scenarios and impact through AI assessment methods, science mapping, responsible AI frameworks, and foresight methodologies

## 🔖 Curriculum Details

Progressively enriching learners' portfolios through documentation, visual synthesis, and live interfaces, this curriculum guides students through a five-stage learning journey. Covering modular web architecture, agentic UX, human–agent orchestration, and public impact synthesis, each stage deepens technical fluency, design imagination, and ethical foresight—**_regardless of prior programming experience_**.

Learners begin by mastering foundational agentic concepts, then develop interfaces and workflows, and finally curate intelligent systems for community engagement and domain impact.

---

### 🧭 Stage 1: Conceptual Foundation — _🌐 TECHC_

Learners build critical digital literacy and sociotechnical awareness through version-controlled notebooks using 🐙 GitHub. This module introduces AI agent technologies and collaborative ecosystems in the human–data–agent triad.

- 🌐 **TECHC: AI Agent Technologies and Collaboration**  
    Students explore open-source platforms, collaborative infrastructures, and ethical foundations. They publish a personal portfolio scaffold with sociotechnical reflections and future learning goals.

---

### 🦾 Stage 2: Practical Interface Foundation — _🐙 AG101, 🐍 PYTHN, 🔍 ANGUX_

Students engage in hands-on development through web design (AG101), Python scripting (PYTHN), and Agent UX research (ANGUX). They prototype reactive front ends and contextual interfaces to structure learning outcomes.

- 🐙 **AG101: Web Development (with AI)**  
    Develop multilingual, component-based websites integrating LLM assistants and CI/CD pipelines.
    
- 🐍 **PYTHN: Python Programming**  
    Use Python to scaffold data logic, API integration, and micro-agent interfaces.
    
- 🔍 **ANGUX: Agent UX Grounding**  
    Apply UX research methods to evaluate user context, consent, and agent adaptability.

## 🧑‍💻 第三阶段：前端应用开发与评估 — _🤗 AG102、⚙️ FRONT（或 📊 INFOV）、🧠 ANGEV模块_

本阶段鼓励学生**构建**智能响应式应用程序。学生将通过🤗 AG102与本地/云端API**开发**界面，使用⚙️ FRONT或📊 INFOV**部署**自适应仪表盘，并以🧠 ANGEV模块**评估**系统行为，侧重情境建模与利益相关方协同。

- 🤗 **AG102：智能网页开发进阶** 在响应式前端应用中，构建基于本地或云端大语言模型API的智能逻辑层。
    
- ⚙️ **FRONT：前端框架开发** _或_ 📊 **INFOV：信息可视化设计** 实现高水平生产型用户界面系统，或设计面向代理系统的可视化仪表盘与交互流程。
    
- 🧠 **ANGEV：代理系统评估** 通过使用者场景模拟，评估用户体验的相关性、伦理适配性及价值协同效果。
    

## 🧠 第四阶段：智能系统集成与推进 — _♞🧱 AG201、♝🍞 AG202、♛🖼️ AG203模块_

学生进入智能系统编排阶段，聚焦结构化沟通（AG201）、RAG管道设计（AG202）与数据可视化（AG203）。本阶段强调语境工程、多语种界面整合与平台感知逻辑设计。

- ♞🧱 **AG201：智能沟通结构设计** 编写产品需求文档（PRD）、提示语层级结构及基于Markdown的用户体验流程，以支持模块化代理系统。
    
- ♝🍞 **AG202：基于RAG的网页开发** 构建具备响应能力的智能管道系统，融合增强检索生成机制与实时知识库。
    
- ♛🖼️ **AG203：智能数据可视化** 设计以数据驱动决策的仪表板，结合平台特性与利益相关方的叙事逻辑。
    

## 🪄 第五阶段：毕业整合与公共影响 — _🧑‍🤝‍🧑🧬 AG303 与 📚🦠 AG302模块_

学生将所学整合为面向公众的智能平台，**呈现**具前瞻性的跨域应用成果。AG303模块鼓励学生**策展**关键实践社群（CoPs）的策略洞见，AG302模块帮助他们**展示**通过科学知识图谱揭示的AI影响力。

- 🧑‍🤝‍🧑🧬 **AG303：智能架构整合与工程实作** 设计并发布具语境感知能力的智能代理平台，面向关键实践社群（如GitHub、Hugging Face）提供价值导向内容。
    
- 📚🦠 **AG302：科学图谱构建与AI影响力分析** 通过引文图谱、专利地形与影响模型，分析并可视化智能趋势与跨域影响。
