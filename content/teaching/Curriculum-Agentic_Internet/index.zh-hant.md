## ⚡TLDR 課程地圖簡介

`{{% param "emoji" %}}{{% param "curriculum" %}}` 為一跨領域智能代理人與 AI 系統導向之課程設計，邀請各系所學生探索快速演進中的代理式應用場景與協作型系統架構。課程融合實作導向與倫理系統思維，涵蓋現代網頁技術、大型語言模型（LLMs）、檢索式增強生成（RAG），並強調代理式使用者體驗（UX）與多模態協作能力。

### 🪜 學習架構

📚 課程共分為 **五大階段**，涵蓋 **🎍10個基礎模組 + 2個畢業專案模組**，引導學生從技術素養逐步發展至系統編排與綜合設計能力。課程架構適配學期制課程或自主節奏學習模式。

### 📘課程階段模組

- 🧭 **第一階段：概念基礎** — _🌐 TECHC_ 建立數位素養，學生將透過 GitHub 編寫版本控制筆記並理解 AI 代理技術與協作生態。模組內容強調「人－資料－代理人」三元互動，以及社會技術反思。
    
- 🦾 **第二階段：實務基礎** — _🐙 AG101, 🐍 PYTHN, 🔍 ANGUX_ 學生進入實作開發，包含模組化網頁介面（AG101）、Python 編程（PYTHN）與情境導向之代理 UX 設計（ANGUX），奠定互動式前端原型與使用者情境編排能力。
    
- 🔁 **第三階段：前端開發與系統評估** — _🤗 AG102, ⚙️ FRONT (或 📊 INFOV), 🧠 ANGEV_ 學生將建置智慧型互動應用，透過 AG102 開發雲端/本地 API 網頁介面並導入 CI/CD 工作流程；選修 FRONT 或 INFOV 可建立適應性資料儀表板；ANGEV 協助評估系統行為、建模場景並使用 Hugging Face 進行互動邏輯測試。
    
- ⛓️ **第四階段：代理強化型開發** — _♞🧱 AG201, ♝🍞 AG202, ♛🖼️ AG203_ 學生進階進入代理系統編排技術，涵蓋結構化溝通（AG201）、RAG 強化資料處理流程（AG202）與評鑑導向之視覺化儀表板設計（AG203）。學生需整合多語代理介面並因應組織與利害關係人的需求，展現代理式推理與價值建模。
    
- 🚀 **第五階段：畢業整合與影響展現** — _🧑‍🤝‍🧑🧬 AG303 & 📚🦠 AG302_ 學生將所設計之代理系統轉化為具備公共呈現力之作品集，展現面向未來的設計價值。AG303 聚焦特定實踐社群（CoP）進行洞察策展，AG302 則藉由專利與學術資料庫進行科學知識圖譜，展現系統敏捷性與情境創新。    

### ✨課程亮點

- 🧭 **導入並實踐** AI 代理技術於特定領域（如商業、金融、醫療、工程），連結領域知識與代理介面設計及互動鏈建構
    
- 🔧 **建構**整合大型語言模型（LLMs）之智能網頁應用，活用 🤗 Hugging Face 與 🐙 GitHub 進行真實案例開發
    
- 📦 **交付與部署**具結構性的表達式智慧系統，涵蓋多語內容、結構化資料、PRD 文件與代理人工作流程
    
- 🔗 **整合並預測**資料、決策與敘事情境，設計符合倫理與適應性的儀表板，提升公共參與並結合程式碼分享與知識圖譜分析
    

### 🎯學習成果

修課結束後，學生將具備以下能力：

- 🧭 **導入與應用** AI 代理技術於特定領域，將代理邏輯與行業實務、目標及知識架構對齊
    
- 🖌️ **建構**使用現代網頁框架的結構化應用與互動式 LLM 系統
    
- 📑 **撰寫**符合產業標準之 AI 代理產品需求文件（PRDs），包含 W3C 無障礙設計與永續網頁規範
    
- 🧰 **溝通**專案決策與價值主張，於相關生態系與實踐社群（CoPs）中進行跨界交流
    
- 🎨 **設計**回應使用者情境與倫理考量之資料視覺化與代理介面
    
- 🧪 **評估**創新場景與其影響力，運用 AI 評鑑方法、科學映射、責任型 AI 架構與前瞻性分析技巧



## 🔖課程體系詳情

本課程通過項目文檔與解釋性成果不斷豐富學生的個人作品集，引導學習者完成一個分階段的學習旅程。每個階段都致力於提升技術熟練度、創新思維、智能系統設計能力與倫理判斷力——**_無需任何編程經驗_**。學習者將從掌握 Web 基礎開始，逐步構建智能界面設計，並最終將創新成果與社會影響進行整合。

這套五階段課程從三個基礎模塊開始，逐步引導學生掌握核心技能，並最終彙聚為兩個畢業項目，從入門學習走向面向現實應用的綜合創新。

### 🧭 第一階段：基礎構建 — _🌐 TECHC_

本階段聚焦於智能體網絡時代的核心素養。學生通過協作式探索和漸進式內容創作，學習社會技術系統的邏輯，練習版本控制系統，並構建個人文檔生態系統。

#### 🌐 TECHC：智能體技術及協作

- 🧠 **關鍵生態技能**：學生通過研究熱門智能開發項目中的社會技術案例，了解互聯網基礎架構、開源平台與協同工作框架。
- 🐙 **GitHub 版本管理**：學生使用 GitHub 進行版本控制、協作編輯，以及基本文件結構和 Markdown 筆記的編寫。
- 📦 **成果交付與展示**：學生開發個人作品集網站，設計首頁並添加行動號召（CTA），用於展示自我介紹與學習目標。


#### 為啥第一階段至關重要 💡

- 🪜 **漸進式成長** —— 提供可復現的筆記本式學習框架，鼓勵學生在個人與同伴互動中實現持續積累，並支持在後續模塊中迭代式發展。
    
- ✏️ **表達力與作者自信** —— 通過寫作、媒介標注與協作式文檔撰寫，培養學生的自我表達能力與知識建構意識。
    
- 🧠 **批判性素養** —— 幫助學生掌握解讀技術系統與數字敘事的核心術語與分析視角，構建跨學科理解力。
    
- 🧰 **開放知識工具的運用能力** —— 使學生熟悉可復現研究、可重混媒介以及社區協作式數據平台的基本使用方法。
    
- 🌍 **開放式創新准備度** —— 將學生連接到開放源碼與開放數據社群，鼓勵其長期參與、重混創作與全球化協作。

### 🦾 第二階段：實務基礎 — _🐙 AG101、♞🧱AG201、📊 INFOV、🧮 ONSUR_

第二階段聚焦於編程、信息表達和用戶體驗思維的實踐探索。學生開始在真實情境中部署智能體系統——搭建響應式網頁界面、設計智能提示語、進行數據可視化，並分析調查反饋。該階段提升學生的社會技術意識，並為有目標、有倫理、有設計敏感度的系統開發奠定基礎。

此階段重點培養學生的系統應用、設計與構建能力，強調技術熟練度與社會技術理解的結合。

#### 🐍 PYTHN：Python 

- 🧠 **腳本編寫能力**：學生練習基礎腳本，掌握變量、函數、控制流與數據結構，為未來的智能邏輯開發打下基礎
- 📊 **數據與模型工具包**：學生運用 Pandas 進行表格操作，使用 Pydantic 定義結構化類型，並基於 Panel 構建 Jupyter 或網頁中的交互式儀表盤
- 📦 **成果展示**：學生提交帶有注釋的 Python 筆記本，如將調查數據轉化為可視化摘要，並鏈接至作品集或智能媒體頁面

#### 🐙 AG101：Web開發

- 🧠 **網頁基礎技能**：學生借助 AI 編程助手學習 Web API 及設計原則，掌握 API、HTTP、HTML、CSS、JavaScript 等基本知識
- 🧩 **模塊化設計**：強調使用 Hugo、TailwindCSS 和 GitHub 工作流程構建響應式、多語種、組件化的網站結構
- 🐙 **GitHub版本控制與協作**：學生使用 GitHub 進行版本管理與項目文檔撰寫，分享可復用模板，並逐步完善成公開作品集
- 📦 **成果展示**：學生最終提交個性化作品集網站，具備響應性、多語言支持和擴展性，正式踏入智能網頁創作的世界

- **是啥**：學生通過結構化編程、利益相關者溝通與數據驅動推理，建立智能體系統的運用素養，涵蓋視覺與統計雙重表達。
- **為啥重要**：學生掌握設計與表達技術，使智能系統回應真實世界的需求、技術限制與組織語境，具備可溝通、可迭代的專業能力。

### 🔁 第三階段：前端開發實踐 — _🤗 AG102、⚙️ FRONT、🐍 PYTHN、🔍 USRES_

第三階段注重智能前端應用的實際開發，結合模塊化 UI 框架、Python 數據工具與以用戶為中心的研究。學生開始構建響應式界面與智能網頁組件，將技術架構轉化為具備倫理與語境意識的自適應體驗。

#### 🤗 AG102：智能體Web開發

- 🛠️ **LLM API集成**：學生在本地與雲端使用 API 接入大語言模型，探索三種架構形式：(1) 公共網站 + 聊天機器人、(2) 私人智能筆記本 + 本地LLM、(3) 視頻平台整合 + 自動化工作流
- 🔄 **智能網頁功能設計**：項目探索網頁組件的反應性、前瞻性與迭代性，打造可適應用戶需求與倫理目標的交互流程
- 🤗 **Hugging Face平台部署**：學生學習使用 Hugging Face 的模型庫與推理 API，部署語言模型並構建定制化智能功能流程
- 📦 **成果展示**：學生提交具有高度結構與交互性的網頁應用，開始理解智能設計如何影響用戶體驗與決策過程

#### ⚙️ FRONT：前端框架

- 🧠 **高級UI開發能力**：學生設計模塊化、多語言布局，使用 Hugo 與 TailwindCSS，並通過輕量級 JS 插件拓展動畫、驗證與交互功能
- 💡 **工具使用與調試能力**：學生管理項目依賴（Node.js 與 NPM）、配置構建腳本，並使用瀏覽器調試工具追蹤智能行為
- 📦 **成果展示**：作品集網站展示響應式設計、JavaScript 增強功能、無障礙體驗與智能化流程，支持多終端與多語種瀏覽


{{% callout success %}} 🔁 第三階段：前端開發實踐 — _🤗 AG102、⚙️ FRONT、🐍 PYTHN、🔍 USRES_

- **是啥**：本階段重點培養前端框架、響應式 UI 組件、Python 數據邏輯及用戶體驗研究方面的技術與設計能力，將界面美學與智能後端有機連接。
- **為啥重要**：學生獲得構建智能、自適應應用的實操能力，使系統能有效響應用戶需求、實現跨學科溝通與協作。

### ⛓️ 第四階段：數據密集型系統開發 — _♝🍞 AG202、♛🖼️ AG203、🎨 UIVIS、💡 PLNFM、🧠 UXANA_

第四階段引導學生進入數據驅動的智能體系統開發，整合檢索增強生成（RAG）流程、自適應儀表盤、界面分析與平台建模。通過前端/UI 技能與數據敘事能力的提升，學生將能夠構建**響應式智能體應用**，並進一步鍛煉**產品管理、用戶體驗研究、以及人與 AI 協作設計**能力。

#### ♞🧱 AG201：智能體通傳結構化

- 🧠 **表達邏輯訓練**：通過 LLM 模型規範、Markdown 圖表、產品需求文檔（PRD）、互動敘事及多語種框架等方式，學生訓練表達的結構化能力
- 🤝 **實踐社群（CoP）參與**：學生在技術生態與行業社群中分享成果，突出設計決策、語境敏感度與信息表達清晰度
- 📦 **成果展示**：學生通過作品集展示出良好的用戶體驗邏輯與文化適應性，項目聚焦於“語境工程”與“提示語工程”，體現智能體系統的表達結構


#### ♝🍞 AG202：RAG 系統設計

- 🔗 **數據結構與檢索機制**：學生設計 RAG 系統，比較結構化與非結構化數據流，探索傳統與知識圖譜式 RAG 架構。
- 🤝 **實踐社群（CoP）連接**：通過實踐社群參與，學生理解新聞、公益科技與學術領域中 RAG 系統的生態差異。
- ⚙️ **前後端整合**：學生開發前端（搜索與聊天功能）與後端（知識語料架構與工作流編排）。
- 📦 **成果展示**：所開發的 RAG 應用可展現動態、語境敏感的交互，呈現智能流程在實際任務中的適應能力。

#### ♛🖼️ AG203：智能體數據可視化

- 👁️‍🗨️ **決策交彙點建模**：學生構建交互式數據儀表盤，除數據本身外，還可呈現決策語境、解釋框架、不確定性與敘事結構。
- 🧩 **人機協同流程**：項目探討人類與智能體在決策流程中的共建機制，強調“人類參與環節”與數據驅動決策邏輯。
- 🧬 **敘事與文化結構**：學生運用視覺語言表達敘事結構、認知框架與文化符號。
- 📦 **成果展示**：最終儀表盤被視為智能體系統，賦予使用者批判性使用數據、協同表達與倫理反思的能力。

### 🚀 第五階段：畢業項目與社會影響 — 🧑‍🤝‍🧑🧬AG303 與 📚🦠AG302

最終階段聚焦於綜合能力與公眾導向的表達，鼓勵學生通過智能系統開發、責任前瞻分析與多語種溝通，**評估**、**構建** 並 **傳達** 自身項目的長期價值。學生通過結構化的自我與同伴評估、專業展示與反饋機制，不斷優化個人作品集，並在以**成果導向評估體系（Outcomes-Based Assessment）**為核心、由**實踐社群（CoP）**指導的框架下完成畢業成果。此階段激發學生的創新思維，要求其清晰地 **辯護設計決策**、**闡述價值主張**，並能在跨文化、跨學科與協作語境中 **解釋影響力**。

### A. 🧩 引言

#### 🧑‍💼 核心崗位角色與團隊技能

🔧 **能力導向型作品集**：個人作品集 🧳 用於 _展示_、_應用_ 和 _優化_ 學習者在技術與社會技術領域中的核心能力。它們作為智能體成長的動態記錄，將模塊化學習成果與以下典型角色能力進行銜接：

- 💻 **Web/軟件開發人員**：掌握系統邏輯、版本控制與端到端部署
    
- 🖼️ **前端開發者或 UI 設計師**：熟練運用多語種界面設計、響應式布局與以人為本的設計系統
    
- 📋 **產品經理或項目經理**：具備智能體系統的整體協調能力，包括文檔工作流、功能規劃與時間線管理
    
- 🧪 **用戶體驗設計師或研究員**：通過服務藍圖、用戶畫像與定性洞察進行扎實的設計調研
    

🔄 **跨崗位與跨領域技能整合**：📁 作品集幫助學習者將自身能力在不同崗位與團隊環境中進行 _展示_、_傳播_ 與 _遷移_。支持終身學習與靈活適應能力，幫助學習者深入 _分析_ 各崗位在項目中的作用，_連接_ 跨學科思維，並高效地與技術、設計、管理和研究同伴進行 _協作_。

- 💻 **Web/軟件開發人員**：_構建_ 技術基礎架構，管理後端自動化，同時 _利用 AI 編程助手_ 進行調試、重構與模塊化流程維護。→ 依賴 UX 與 PM 團隊的反饋來 _優先考慮_ 用戶需求與平台目標相關的功能。
    
- 🖼️ **前端開發者或 UI 設計師**：_調整_ 多語種響應式界面，使用設計系統並 _與 AI 設計助手協作_ 生成交互組件與優化布局。→ 根據 UX 團隊提供的線框圖與洞察，結合開發者與產品經理的反饋調整流程。
    
- 📋 **產品經理或項目經理**：_定義_ 功能優先級，通過 MRD、PRD 與平台地圖實現目標對齊，並 _運用 AI 編程與設計助手_ 模擬時間線與系統調度流程。→ 依賴開發團隊的可行性分析與 UX 團隊的可用性評估來 _驗證_ 策略決策。
    
- 🧪 **用戶體驗設計師或研究員**：_分析_ 用戶反饋，通過 AI 設計助手模擬服務路徑，優化智能體交互的跨文化與多場景表現。→ 整合來自開發者部署應用、設計師界面組件與 PM 戰略約束的數據，為用戶體驗提升 _提供依據_。
    

#### 🧠 運作機制說明

為清晰展示知識積累與團隊協作意識如何在學習過程中形成與深化，本課程將作品集開發融入以下三個教育路徑：

- 👥 **崗位角色與團隊技能**：學習者通過 _探索_ 與 _分析_ 各崗位在協作式產品開發中的貢獻，建立跨學科溝通能力與知識共同創造意識。
    
- 🧠 **學習進程與能力成長軌跡**：學生將真實項目制成果（如 MRD、PRD、用戶體驗圖、利益相關者畫布、運行中的應用原型）進行 _構思_、_迭代_ 與 _優化_，從 _個體行動_ 到 _團隊角色_ 展現智能能力成長與自我覺察。

##### 💛 為什麼這條主線重要 🧱

該模塊組體現了技術發展的“漸進技能路徑”，從響應式網頁設計逐步提升至智能體系統部署，強調模塊化、自動化與應用智能能力。

    - 從 🐙 `AG101` 起步，掌握界面設計及作品集構建
    - 進階 🤗 `AG102` 與 🐍 `PYTHN`，深入理解邏輯腳本、數據自動化與 LLM 協同部署流程
    - 最終通過 ♝🍞 `AG202`，開發基於 RAG 與 API 的智能體原型，配套成本評估與 PRD 產品文檔
- 🧪 **智能體學習路徑**：通過實踐實驗室、同伴評議與價值定位文檔循環，學生將強化以下能力：
    
    - 設計與部署反映用戶需求與組織目標的智能應用
    - 在日常工作流程中嵌入設計助手與生成式智能體
    - 將 LLM 模型集成至可落地的部署架構
    - 運用數據分析、成本效益與利益相關者指標評估開發決策
- 📱 **綜合能力支柱**：該技術主線融合以下四類核心技術能力：
    
    - **視覺與結構構建**：模塊化網頁布局與響應式設計（🐙 `AG101`）
    - **智能優化與協同編排**：界面邏輯、評估流程與迭代部署（🤗 `AG102`）
    - **信息處理能力**：數據整理與腳本自動化（🐍 `PYTHN`）
    - **互動智能能力**：構建具 RAG 功能的智能服務與適應性用戶流程（♝🍞 `AG202`）
- 🛠️ **畢業項目對接能力**：該模塊組強化 CI/CD 流暢度、模塊化開發習慣與智能體系統原型能力，直接支撐最終畢業項目（📚🦠 `AG302`、🧑‍🤝‍🧑🧬 `AG303`）中的部署、文檔編寫與評估邏輯設計

這條技術主線與 PM、UI 和 UX 其他主線相輔相成，構建一個以社會技術為導向的綜合課程體系，引導學生成為具備思辨力的 AI 驅動網站系統設計者。

該主線幫助學生引導項目從構思到部署，培養他們成為協同制作的思維領導者，將技術能力與價值導向創新整合起來。

重點培養智能體素養，涵蓋利益相關者協調、平台創新與系統級協作：

- 🌐 `TECHC`：
    
    - 引入智能媒體系統的基礎架構思維與協同工作流
    - 是開發者節點（如 `AG101`、`AG202`）與社會技術評估模塊（如 `ONSUR`、`BIGDA`）的連接起點
- ♞🧱 `AG201`：
    
    - 提供管理團隊動態與戰略傳播的框架
    - 培養對利益相關者角色、價值一致性與平台治理的反思性理解
- 💡 `PLNFM`：
    
    - 運用戰略思維分析平台生態、網絡效應與服務盈利模式
    - 作為 PM 主線的總結模塊，提供智能體編排與可持續增長的綜合視角

##### 💛 為什麼 PM 主線重要 🎁🪄

該模塊群幫助學生將智能系統開發從構思推進到落地交付，將社會技術推理、利益相關者協調與創新領導力融入產品生命周期的每一個階段。

教學優勢與核心能力包括：

- 🎯 **全流程掌握**：學生規劃、執行並部署項目，從初期構想到可上線交付
- 🤝 **協作引導力**：培養跨職能團隊協作與實踐社群參與能力，應對復雜的社會技術挑戰
- 🧠 **戰略協調能力**：圍繞利益相關者價值、市場契合度與功能交付邏輯進行智能系統開發規劃
- 🪡 **溝通表達設計**：構建平台敘事、服務藍圖與產品需求邏輯的表達支架
- 📡 **社會技術素養**：將倫理、基礎設施與組織洞察轉化為服務規劃與創新框架
- 🚀 **創新領導力**：通過反饋機制與平台影響分析推動持續優化與數據驅動創新
- 🛰️ **生態系統錨定力**：連接開發（黃色）、UI（粉色）、UX（藍色）主線，支撐整個課程體系中的智能體素養發展

#### 4. 💓 用戶體驗主線（藍色）

UX 主線以**藍色節點**呈現，代表課程體系中**以人為本的設計能力**，融合嚴謹的研究方法、統計分析與體驗洞察。對應角色包括 UX 研究員、體驗策略師與服務設計師等，致力於彌合用戶需求與產品解決方案之間的差距。

在課程圖中位於底部，這些節點構成了研究基礎與反饋通路，為上游設計、開發與平台協調提供依據與洞察。

##### 🧩 核心模塊

該主線幫助學生通過問卷調查與質性研究理解用戶，將數據轉化為可操作的 UX 洞察，並迭代提升可用性、滿意度與長期互動體驗：

- 🧮 `ONSUR`：
    
    - 引導問卷設計、抽樣技術與統計分析，實現可應用的用戶研究
    - 將基礎架構邏輯（`TECHC`）與研究方法及社會洞察相連接
- 🔍 `USRES`：
    
    - 開展深度訪談、情境調研與可用性測試，識別用戶行為與服務缺口
    - 在課程圖中交叉連接 PM 與設計主線，提供體驗評估與價值建模路徑
- 🧠 `UXANA`：
    
    - 運用情感分析、用戶旅程建模與基於 RAG 的解釋邏輯，將原始數據轉化為 UX 洞察
    - 支持平台評估與界面演化，奠定社會技術素養基礎

##### 😽 為什麼 UX 主線重要 🎁💓

- 🔎 **同理心驅動的研究**：通過質性訪談與量化問卷深入理解用戶動機、痛點與使用語境，確保設計以人為本、從真實體驗出發。
    
- 🛠️ **迭代式優化能力**：引導學生開展可用性測試、分析反饋數據，並持續優化界面與用戶旅程，實現對動態需求的敏捷響應。
    
- 📊 **數據支持的設計決策**：整合統計分析與用戶調研成果，將可量化目標與情境洞察結合，實現基於證據的設計升級。
    
- 🤝 **用戶倡導力與聲音表達**：培養學生在跨職能團隊中代表用戶立場，強調設計中的包容性、可訪問性與倫理責任。
    
- 🔄 **可持續反饋生態**：在 UX 工作流中嵌入長期的評估機制與用戶反饋循環，支持產品適應技術演進與服務預期變化。
    
- 🧠 **Agent UX 專業素養**：介紹智能體體驗設計理念，將 AI 模型、編排邏輯與工具集成至用戶任務中。學生將學習信任度、透明性、控制感與多模態交互等 Agent UX 原則，打造自然、安全並具備語境敏感度的智能體驗。
    
- 🌐 **跨主線連接能力**：UX 洞察可反哺至產品管理策略、界面邏輯與開發流程，使 UX 成為貫穿課程體系與畢業項目的“人本價值引導線”，支撐智能體系統的社會技術落地。

### C. 🎯 教育即最小可行產品（MVP）

本課程體系倡導“教育即最小可行產品（MVP）”理念 —— 優先傳授使學生能夠自信且負責任地在真實崗位上實踐的關鍵知識。相較於記住零散的事實（**知道是什麼 know-whats**），學生更注重**理解為什麼 know-whys**，並由此激發**知道怎麼做 know-hows** —— 即可應用的專業實踐能力。

---

#### 🧭 知道“為什麼”的機制（Know-Whys）

為了幫助學生通過反復練習與自我覺察內化技能，課程提供以下結構性支架，引導深入的概念學習：

- 🎯 **畢業項目（Capstone Projects）**：最終作品集作為項目制學習的結晶，融合技術性與社會技術性知識成果
- 👥 **崗位角色協作機制**：四大職業主線模擬跨學科團隊合作，反映產品生命周期中的角色分工與協同邏輯
- 🧠 **漸進式學習循環**：通過編寫真實世界文檔（如 MRD、PRD、UX 流程圖），學生構建認知工具，用以處理不確定性、顯化設計意圖，並將願景轉化為行動 —— 從“解決問題的英雄”成長為“塑造系統的智能體”

---

#### 🛠️ 知道“怎麼做”的機制（Know-Hows）

技能塑造源自沉浸式角色扮演，學生在模擬的職業實踐中承擔決策責任並親歷系統開發流程：

- 📌 項目經理撰寫概要與規劃路線圖
- 🧩 設計師制作界面原型並記錄視覺邏輯
- 🔍 用戶研究員繪制用戶旅程圖並分析系統價值

所有任務均圍繞協同創作與階段性反思進行組織。

---

#### 📦 學習成果：作品集即為 MVP

作品集是學習成長的核心呈現 —— 既是成果記錄，也是項目制能力的動態展示：

- 💼 學生交付最終作品集，作為由多個 MVP 項目組成的整合成果，每項均體現出對知識的實踐理解
- 🧑‍💻 學生通過領域特定的表達格式與文檔展現出在行業角色（產品經理、前端/UI 設計、UX 研究與設計）中的專業流暢度
- 🔗 學生跨主線協作，貢獻的成果包括 MRD、BRD、PRD 文檔；數據儀表盤、應用原型、UI 套件；用戶研究報告、市場概要、技術規範與反思性論文等
