## 🏎️ Common Racing Flags (with emoji)

| Flag Name      | Meaning                    | Emoji |
| -------------- | -------------------------- | ----- |
| Green Flag     | Start / Resume racing      | 🟢    |
| Yellow Flag    | Caution / Slow down        | 🟡    |
| Red Flag       | Stop race immediately      | 🟥    |
| Blue Flag      | Let faster car pass        | 🔵    |
| Black Flag     | Disqualification / Penalty | ⚫     |
| White Flag     | Final lap                  | ⚪     |
| Chequered Flag | Race finished              | 🏁    |

Let me know if you want to explore how these flags are used in Formula 1, NASCAR, or other racing formats!
