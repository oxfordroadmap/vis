## ⚡TLDR 课程体系简介

该`{{% param "emoji" %}}{{% param "curriculum" %}}` 课程体系引导学习者探索 AI 集成网页系统的前沿，重点强调智能体设计、多语种适配与 RAG（检索增强生成）逻辑。通过模块化学习与实践导向项目，学生不仅掌握应用开发，更学会如何构建智能体系统、表达建模决策语境，并在伦理、协作和数据响应的架构中思考未来智能创新。


📚课程分为**三个循序渐进的阶段**，共包含**5+2 个课程模块**，可灵活适应（大学）学期制 或 自主学习节奏 安排：

- 🧭 **第一阶段：基础构建** — _AG101 至 AG102_：通过 API 实现智能体功能，学生掌握网页应用开发基础技能，并通过平台如 🤗 Hugging Face 和 🐙 GitHub 集成语言模型。
    
- 🔁 **第二阶段：产出创作** — _AG201 至 AG203_：学生通过结构化表达、RAG 系统与智能体数据仪表盘，开发具响应性、多语及智能解释能力的应用。
    
- 🚀 **第三阶段：影响力总结** — _AG301 和 AG302_：学生将学习成果项目整合为可公开访问的作品集，开展科学知识图谱绘制，并通过预测与前瞻性方法评估 AI 创新影响。    

### ✨课程亮点

- 🔧 **构建** 集成大型语言模型（LLM）的智能体网页应用，结合 🤗 Hugging Face 和 🐙 GitHub 的代理性 Web 应用，实现真实场景功能
    
- 📦 **交付与部署** 多语种表达系统，结合结构化数据、产品需求文档（PRD）与智能体工作流，实现智能部署
    
- 🔗 **整合与预测** 数据、决策与叙事内容，打造具伦理意识的适应型仪表板，包括代码共享开源与科学知识图谱绘制成果展示
        

### 🎯学习成果

课程结束后，学生将具备以下能力：

- 🖌️ **构建** 基于现代 Web 框架的结构化网页应用 与 交互式 LLM 系统
- 📑 **撰写** 能生成可行代码、对齐 W3C 无障碍标准与可持续设计理念的专业 `智能体产品需求文档`（智能体PRD）
- 🧰 **沟通** 项目决策与价值主张，面向相关技术生态与实践社群（CoPs）    
- 🎨 **设计** 响应用户语境与伦理考量的数据可视化与智能体界面
- 🧪 **评估** 使用 AI 评估方法、科学知识图谱绘制工具、责任 AI 框架与前瞻性方法识别创新场景与影响路径


## 🔖课程体系详情

本课程通过项目文档与解释性成果不断丰富学生的个人作品集，引导学习者完成一个分阶段的学习旅程。每个阶段都致力于提升技术熟练度、创新思维、智能系统设计能力与伦理判断力——**_无需任何编程经验_**。学习者将从掌握 Web 基础开始，逐步构建智能界面设计，并最终将创新成果与社会影响进行整合。

这套五阶段课程从三个基础模块开始，逐步引导学生掌握核心技能，并最终汇聚为两个毕业项目，从入门学习走向面向现实应用的综合创新。

### 🧭 第一阶段：基础构建 — _🌐 TECHC、📡 INTRO、✍️ COPYE_

本阶段聚焦于智能体网络时代的核心素养。学生通过协作式探索和渐进式内容创作，学习社会技术系统的逻辑，练习版本控制系统，并构建个人文档生态系统。

#### 🌐 TECHC：智能体技术及协作

- 🧠 **关键生态技能**：学生通过研究热门智能开发项目中的社会技术案例，了解互联网基础架构、开源平台与协同工作框架。
- 🐙 **GitHub 版本管理**：学生使用 GitHub 进行版本控制、协作编辑，以及基本文件结构和 Markdown 笔记的编写。
- 📦 **成果交付与展示**：学生开发个人作品集网站，设计首页并添加行动号召（CTA），用于展示自我介绍与学习目标。

#### 📡 INTRO：智能体导论

- 🧠 **数字传播核心概念**：学生深入理解智能代理系统，探索 AI 如何在数字平台中解读、生成并传递信息。
- 🔍 **智能演化史与未来**：学生追踪从早期控制论到当代 智能体的发展历程，理解自治、决策与交互的社会技术模型。
- 📦 **成果交付与展示**：学生提交个人作品集网站，通过首页 CTA 展示其智能角色档案、学习目标或 AI 人设草图。

#### ✍️ COPYE：文案编辑与创意写作（结合 AI 辅助工具）

- 🧠 **写作与编辑能力**：学生通过语义图谱、提示设计与风格转换技术提升语言清晰度、语气与结构能力，并根据 Bloom 分类法优化写作表达。
- 💬 **语料改写与 AI 协作创作**：学生探索语料重构、AI 协作写作与反馈迭代过程，深入分析文体变化与协作文本的伦理争议。
- 😂 **段子写作与语感训练**：学生通过构建笑点、观察社交线索、设计幽默提示语等练习，提升语气控制与时间把握能力。
- 📦 **成果交付与展示**：学生提交含有版本记录的写作笔记，包含协作文本片段、笑点草图与提示模板，并将其集成到个人作品集网站，附带语义图谱与风格展示用的 CTA。

#### 为啥第一阶段至关重要 💡

- 🪜 **渐进式成长** —— 提供可复现的笔记本式学习框架，鼓励学生在个人与同伴互动中实现持续积累，并支持在后续模块中迭代式发展。
    
- ✏️ **表达力与作者自信** —— 通过写作、媒介标注与协作式文档撰写，培养学生的自我表达能力与知识建构意识。
    
- 🧠 **批判性素养** —— 帮助学生掌握解读技术系统与数字叙事的核心术语与分析视角，构建跨学科理解力。
    
- 🧰 **开放知识工具的运用能力** —— 使学生熟悉可复现研究、可重混媒介以及社区协作式数据平台的基本使用方法。
    
- 🌍 **开放式创新准备度** —— 将学生连接到开放源码与开放数据社群，鼓励其长期参与、重混创作与全球化协作。

### 🦾 第二阶段：实务基础 — _🐙 AG101、♞🧱AG201、📊 INFOV、🧮 ONSUR_

第二阶段聚焦于编程、信息表达和计算思维的实践探索。学生开始在真实情境中部署智能体系统——搭建响应式网页界面、设计智能提示语、进行数据可视化，并分析调查反馈。该阶段提升学生的社会技术意识，并为有目标、有伦理、有设计敏感度的系统开发奠定基础。

此阶段重点培养学生的系统应用、设计与构建能力，强调技术熟练度与社会技术理解的结合。

#### 🐙 AG101：Web开发

- 🧠 **网页基础技能**：学生借助 AI 编程助手学习 Web API 及设计原则，掌握 API、HTTP、HTML、CSS、JavaScript 等基本知识
- 🧩 **模块化设计**：强调使用 Hugo、TailwindCSS 和 GitHub 工作流程构建响应式、多语种、组件化的网站结构
- 🐙 **GitHub版本控制与协作**：学生使用 GitHub 进行版本管理与项目文档撰写，分享可复用模板，并逐步完善成公开作品集
- 📦 **成果展示**：学生最终提交个性化作品集网站，具备响应性、多语言支持和扩展性，正式踏入智能网页创作的世界

#### ♞🧱 AG201：智能体通传结构化

- 🧠 **表达逻辑训练**：通过 LLM 模型规范、Markdown 图表、产品需求文档（PRD）、互动叙事及多语种框架等方式，学生训练表达的结构化能力
- 🤝 **实践社群（CoP）参与**：学生在技术生态与行业社群中分享成果，突出设计决策、语境敏感度与信息表达清晰度
- 📦 **成果展示**：学生通过作品集展示出良好的用户体验逻辑与文化适应性，项目聚焦于“语境工程”与“提示语工程”，体现智能体系统的表达结构

#### 📊 INFOV：信息可视化

- 🧠 **数据叙事与图形素养**：学生学会整理原始数据、选择合适图表类型，并构建清晰的视觉叙述，与用户行为、文化解读与语境相关
- 🎨 **工具与模板运用**：探索如 Mermaid.js、D3.js 等可视化库，以及轻量级无代码工具，用于生成智能媒介系统的流程图与结构图
- 📦 **成果展示**：学生将可视化成果嵌入个人作品集中，包括注释时间轴、交互式图表等，以呈现信息流动、智能体行为及社会技术接口逻辑，进而体现数据整合与设计表达的能力

#### 🧮 ONSUR：在线调查与统计分析

- 🧠 **社会技术调查与数据推理**：学生提出研究问题，设计调查问卷，使用开源工具收集结构化反馈，并运用基础统计与可视化方法分析数据模式与反馈信息
- 💬 **调查平台工具应用**：探索 Typeform、Google Forms 或自定义 Markdown 表单平台，注重可访问性、多语种清晰表达与以用户为中心的设计
- 📦 **成果展示**：学生提交信息图或仪表盘，总结利益相关者反馈内容，与智能体系统目标对齐，并引导关于设计假设的讨论

{{% callout success %}} 🦾 第二阶段：实务基础

- **是啥**：学生通过结构化编程、利益相关者沟通与数据驱动推理，建立智能体系统的运用素养，涵盖视觉与统计双重表达。
- **为啥重要**：学生掌握设计与表达技术，使智能系统回应真实世界的需求、技术限制与组织语境，具备可沟通、可迭代的专业能力。

### 🔁 第三阶段：前端开发实践 — _🤗 AG102、⚙️ FRONT、🐍 PYTHN、🔍 USRES_

第三阶段注重智能前端应用的实际开发，结合模块化 UI 框架、Python 数据工具与以用户为中心的研究。学生开始构建响应式界面与智能网页组件，将技术架构转化为具备伦理与语境意识的自适应体验。

#### 🤗 AG102：智能体Web开发

- 🛠️ **LLM API集成**：学生在本地与云端使用 API 接入大语言模型，探索三种架构形式：(1) 公共网站 + 聊天机器人、(2) 私人智能笔记本 + 本地LLM、(3) 视频平台整合 + 自动化工作流
- 🔄 **智能网页功能设计**：项目探索网页组件的反应性、前瞻性与迭代性，打造可适应用户需求与伦理目标的交互流程
- 🤗 **Hugging Face平台部署**：学生学习使用 Hugging Face 的模型库与推理 API，部署语言模型并构建定制化智能功能流程
- 📦 **成果展示**：学生提交具有高度结构与交互性的网页应用，开始理解智能设计如何影响用户体验与决策过程

#### ⚙️ FRONT：前端框架

- 🧠 **高级UI开发能力**：学生设计模块化、多语言布局，使用 Hugo 与 TailwindCSS，并通过轻量级 JS 插件拓展动画、验证与交互功能
- 💡 **工具使用与调试能力**：学生管理项目依赖（Node.js 与 NPM）、配置构建脚本，并使用浏览器调试工具追踪智能行为
- 📦 **成果展示**：作品集网站展示响应式设计、JavaScript 增强功能、无障碍体验与智能化流程，支持多终端与多语种浏览

#### 🐍 PYTHN：Python 

- 🧠 **脚本编写能力**：学生练习基础脚本，掌握变量、函数、控制流与数据结构，为未来的智能逻辑开发打下基础
- 📊 **数据与模型工具包**：学生运用 Pandas 进行表格操作，使用 Pydantic 定义结构化类型，并基于 Panel 构建 Jupyter 或网页中的交互式仪表盘
- 📦 **成果展示**：学生提交带有注释的 Python 笔记本，如将调查数据转化为可视化摘要，并链接至作品集或智能媒体页面

### ⛓️ 第四阶段：数据密集型系统开发 — _♝🍞 AG202、♛🖼️ AG203、🎨 UIVIS、💡 PLNFM、🧠 UXANA_

第四阶段引导学生进入数据驱动的智能体系统开发，整合检索增强生成（RAG）流程、自适应仪表盘、界面分析与平台建模。通过前端/UI 技能与数据叙事能力的提升，学生将能够构建**响应式智能体应用**，并进一步锻炼**产品管理、用户体验研究、以及人与 AI 协作设计**能力。

#### ♝🍞 AG202：检索增强生成系统

- 🔗 **数据结构与检索机制**：学生设计 RAG 系统，比较结构化与非结构化数据流，探索传统与知识图谱式 RAG 架构。
- 🤝 **实践社群（CoP）连接**：通过实践社群参与，学生理解新闻、公益科技与学术领域中 RAG 系统的生态差异。
- ⚙️ **前后端整合**：学生开发前端（搜索与聊天功能）与后端（知识语料架构与工作流编排）。
- 📦 **成果展示**：所开发的 RAG 应用可展现动态、语境敏感的交互，呈现智能流程在实际任务中的适应能力。

#### ♛🖼️ AG203：智能体数据可视化

- 👁️‍🗨️ **决策交汇点建模**：学生构建交互式数据仪表盘，除数据本身外，还可呈现决策语境、解释框架、不确定性与叙事结构。
- 🧩 **人机协同流程**：项目探讨人类与智能体在决策流程中的共建机制，强调“人类参与环节”与数据驱动决策逻辑。
- 🧬 **叙事与文化结构**：学生运用视觉语言表达叙事结构、认知框架与文化符号。
- 📦 **成果展示**：最终仪表盘被视为智能体系统，赋予使用者批判性使用数据、协同表达与伦理反思的能力。

#### 🎨 UIVIS：用户与视觉界面设计

- 🧠 **设计智能界面组件**：学生构建能够体现社会技术语境、理解用户行为，并动态适配多语种与多模态输入的 UI 元素。
    
- 🛠️ **原型制作与用户流程**：学生使用模块化工具和类 Figma 平台，构建响应式界面原型和用户旅程图，设计过程参考 UXANA 的洞察。
    
- 🔍 **分析生态设计模板**：学生调研 Figma 社区设计包、TailwindCSS 模板、Hugging Face、LobeChat 和 GitHub Discussions 等平台的 UI 模式，重点在于借鉴与适配。
    
- 🧩 **优化现有界面组件**：学生对预构建的 UI 元件进行修改与升级，提升多语种支持、无障碍设计与智能体兼容性，依据 UXANA 批判性反馈进行调整。
    
- 🎛️ **界面信息表达与结构化**：学生应用解释性框架对布局设计、可访问性流程和界面语言进行调整，使智能体的决策点具有清晰的视觉表达形式。
    
- 📦 **成果交付与展示**：最终 UI 作品嵌入网页或仪表盘系统，并附带批注与设计逻辑说明，展示界面的响应性与智能交互结构。
#### 💡 PLNFM：平台经济与创新

- 🧠 **平台架构与价值模型**：学生 _绘制_ 平台如何通过 API、用户数据与智能体集成创造价值，分析创意工具、公益科技与联邦平台的案例。
- 📊 **利益相关方对齐与设计画布**：学生 _构建_ 产品蓝图，如市场需求文档（MRD）、业务需求文档（BRD）与平台画布，用以明确用户需求、智能体角色与伦理限制。
- 🧭 **治理机制与创新比较**：学生 _整合_ 平台治理模式，对比激励结构、创意劳动协商机制与智能体盈利模型。
- 📦 **成果展示**：学生 _提交_ 利益相关者地图、平台生态模型与 MRD/BRD 原型，将设计逻辑落地于平台运营与多边网络语境中。

### A. 🧩 引言

#### 🧑‍💼 核心岗位角色与团队技能

🔧 **能力导向型作品集**：个人作品集 🧳 用于 _展示_、_应用_ 和 _优化_ 学习者在技术与社会技术领域中的核心能力。它们作为智能体成长的动态记录，将模块化学习成果与以下典型角色能力进行衔接：

- 💻 **Web/软件开发人员**：掌握系统逻辑、版本控制与端到端部署
    
- 🖼️ **前端开发者或 UI 设计师**：熟练运用多语种界面设计、响应式布局与以人为本的设计系统
    
- 📋 **产品经理或项目经理**：具备智能体系统的整体协调能力，包括文档工作流、功能规划与时间线管理
    
- 🧪 **用户体验设计师或研究员**：通过服务蓝图、用户画像与定性洞察进行扎实的设计调研
    

🔄 **跨岗位与跨领域技能整合**：📁 作品集帮助学习者将自身能力在不同岗位与团队环境中进行 _展示_、_传播_ 与 _迁移_。支持终身学习与灵活适应能力，帮助学习者深入 _分析_ 各岗位在项目中的作用，_连接_ 跨学科思维，并高效地与技术、设计、管理和研究同伴进行 _协作_。

- 💻 **Web/软件开发人员**：_构建_ 技术基础架构，管理后端自动化，同时 _利用 AI 编程助手_ 进行调试、重构与模块化流程维护。→ 依赖 UX 与 PM 团队的反馈来 _优先考虑_ 用户需求与平台目标相关的功能。
    
- 🖼️ **前端开发者或 UI 设计师**：_调整_ 多语种响应式界面，使用设计系统并 _与 AI 设计助手协作_ 生成交互组件与优化布局。→ 根据 UX 团队提供的线框图与洞察，结合开发者与产品经理的反馈调整流程。
    
- 📋 **产品经理或项目经理**：_定义_ 功能优先级，通过 MRD、PRD 与平台地图实现目标对齐，并 _运用 AI 编程与设计助手_ 模拟时间线与系统调度流程。→ 依赖开发团队的可行性分析与 UX 团队的可用性评估来 _验证_ 策略决策。
    
- 🧪 **用户体验设计师或研究员**：_分析_ 用户反馈，通过 AI 设计助手模拟服务路径，优化智能体交互的跨文化与多场景表现。→ 整合来自开发者部署应用、设计师界面组件与 PM 战略约束的数据，为用户体验提升 _提供依据_。

- 🎯 **全流程掌握**：学生规划、执行并部署项目，从初期构想到可上线交付
- 🤝 **协作引导力**：培养跨职能团队协作与实践社群参与能力，应对复杂的社会技术挑战
- 🧠 **战略协调能力**：围绕利益相关者价值、市场契合度与功能交付逻辑进行智能系统开发规划
- 🪡 **沟通表达设计**：构建平台叙事、服务蓝图与产品需求逻辑的表达支架
- 📡 **社会技术素养**：将伦理、基础设施与组织洞察转化为服务规划与创新框架
- 🚀 **创新领导力**：通过反馈机制与平台影响分析推动持续优化与数据驱动创新
- 🛰️ **生态系统锚定力**：连接开发（黄色）、UI（粉色）、UX（蓝色）主线，支撑整个课程体系中的智能体素养发展

#### 4. 💓 用户体验主线（蓝色）

UX 主线以**蓝色节点**呈现，代表课程体系中**以人为本的设计能力**，融合严谨的研究方法、统计分析与体验洞察。对应角色包括 UX 研究员、体验策略师与服务设计师等，致力于弥合用户需求与产品解决方案之间的差距。

在课程图中位于底部，这些节点构成了研究基础与反馈通路，为上游设计、开发与平台协调提供依据与洞察。

##### 🧩 核心模块

该主线帮助学生通过问卷调查与质性研究理解用户，将数据转化为可操作的 UX 洞察，并迭代提升可用性、满意度与长期互动体验：

- 🧮 `ONSUR`：
    
    - 引导问卷设计、抽样技术与统计分析，实现可应用的用户研究
    - 将基础架构逻辑（`TECHC`）与研究方法及社会洞察相连接
- 🔍 `USRES`：
    
    - 开展深度访谈、情境调研与可用性测试，识别用户行为与服务缺口
    - 在课程图中交叉连接 PM 与设计主线，提供体验评估与价值建模路径
- 🧠 `UXANA`：
    
    - 运用情感分析、用户旅程建模与基于 RAG 的解释逻辑，将原始数据转化为 UX 洞察
    - 支持平台评估与界面演化，奠定社会技术素养基础

##### 😽 为什么 UX 主线重要 🎁💓

- 🔎 **同理心驱动的研究**：通过质性访谈与量化问卷深入理解用户动机、痛点与使用语境，确保设计以人为本、从真实体验出发。
    
- 🛠️ **迭代式优化能力**：引导学生开展可用性测试、分析反馈数据，并持续优化界面与用户旅程，实现对动态需求的敏捷响应。
    
- 📊 **数据支持的设计决策**：整合统计分析与用户调研成果，将可量化目标与情境洞察结合，实现基于证据的设计升级。
    
- 🤝 **用户倡导力与声音表达**：培养学生在跨职能团队中代表用户立场，强调设计中的包容性、可访问性与伦理责任。
    
- 🔄 **可持续反馈生态**：在 UX 工作流中嵌入长期的评估机制与用户反馈循环，支持产品适应技术演进与服务预期变化。
    
- 🧠 **Agent UX 专业素养**：介绍智能体体验设计理念，将 AI 模型、编排逻辑与工具集成至用户任务中。学生将学习信任度、透明性、控制感与多模态交互等 Agent UX 原则，打造自然、安全并具备语境敏感度的智能体验。
    
- 🌐 **跨主线连接能力**：UX 洞察可反哺至产品管理策略、界面逻辑与开发流程，使 UX 成为贯穿课程体系与毕业项目的“人本价值引导线”，支撑智能体系统的社会技术落地。

### C. 🎯 教育即最小可行产品（MVP）

本课程体系倡导“教育即最小可行产品（MVP）”理念 —— 优先传授使学生能够自信且负责任地在真实岗位上实践的关键知识。相较于记住零散的事实（**知道是什么 know-whats**），学生更注重**理解为什么 know-whys**，并由此激发**知道怎么做 know-hows** —— 即可应用的专业实践能力。

---

#### 🧭 知道“为什么”的机制（Know-Whys）

为了帮助学生通过反复练习与自我觉察内化技能，课程提供以下结构性支架，引导深入的概念学习：

- 🎯 **毕业项目（Capstone Projects）**：最终作品集作为项目制学习的结晶，融合技术性与社会技术性知识成果
- 👥 **岗位角色协作机制**：四大职业主线模拟跨学科团队合作，反映产品生命周期中的角色分工与协同逻辑
- 🧠 **渐进式学习循环**：通过编写真实世界文档（如 MRD、PRD、UX 流程图），学生构建认知工具，用以处理不确定性、显化设计意图，并将愿景转化为行动 —— 从“解决问题的英雄”成长为“塑造系统的智能体”

---

#### 🛠️ 知道“怎么做”的机制（Know-Hows）

技能塑造源自沉浸式角色扮演，学生在模拟的职业实践中承担决策责任并亲历系统开发流程：

- 📌 项目经理撰写概要与规划路线图
- 🧩 设计师制作界面原型并记录视觉逻辑
- 🔍 用户研究员绘制用户旅程图并分析系统价值

所有任务均围绕协同创作与阶段性反思进行组织。

---

#### 📦 学习成果：作品集即为 MVP

作品集是学习成长的核心呈现 —— 既是成果记录，也是项目制能力的动态展示：

- 💼 学生交付最终作品集，作为由多个 MVP 项目组成的整合成果，每项均体现出对知识的实践理解
- 🧑‍💻 学生通过领域特定的表达格式与文档展现出在行业角色（产品经理、前端/UI 设计、UX 研究与设计）中的专业流畅度
- 🔗 学生跨主线协作，贡献的成果包括 MRD、BRD、PRD 文档；数据仪表盘、应用原型、UI 套件；用户研究报告、市场概要、技术规范与反思性论文等
