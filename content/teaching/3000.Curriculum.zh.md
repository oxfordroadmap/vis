# ⓷ 课程方案（专业人才培养方案）概览 🛣️

对于没有软件开发背景的学习者，以下四个版本的课程可能对学习者和教育者都有帮助。

---

### 四个版本

以下四个版本适用于**_没有任何软件开发知识的学习者_**：

#### 🪴 `Agentic Web Development`【智能体应用开发】

- 🗓️ **（精简版）5+2 课程**
    - 🥯 最精简且更新的课程，融合了 Web 与 AI Agent 的开发学习
    - 🧐 适用于黑客松、暑期学校或继续教育

#### 🌲 `AI Agent & Internet` 【智能体与互联网】

- 🗓️ **（核心版）10+2 课程**
    - 🥪 一套精简且更新的课程
    - 🤖 提供融合 Web 与 AI Agent 的开发学习
    - 🧑🏾‍🏫 适用于任何本科项目

#### 🎄 `Agentic New Media & Internet`【智能体时代下的网路与新媒体】

- 🗓️ **（完整版）修订后的 18 门课程**
    - 🍔 更新为最新的 Web 与 AI Agent 开发学习内容
    - 🎯 适用于培养互联网领域的 **产品经理**、**UI/UX 设计师** 和 **前端开发者**
    - 🧠 专注于整合 **AI Agent 能力** 与其他 **API 资源**，以解决实际问题

#### 🌲 `New Media & Internet`【网路与新媒体】

- 🗓️ **（基础版）原始 19 门课程**
    - 🏫 已在中国某高校实施并执行
    - 🎯 重点培养互联网领域的 **产品经理**、**UI/UX 设计师** 和 **前端开发者**
    - ☁️ 强调 **API 云资源**整合开发能力
